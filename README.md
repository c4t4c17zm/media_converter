# C0_0nverter

Нативное настольное приложение Windows для перекодирования аудио и видео. Браузер не используется, файлы обрабатываются локально.

## Запуск

Запустите `dist/C0_0nverter.exe`. Выберите исходный файл и контейнер, откройте «Настройки кодирования…», задайте кодек и параметры, затем нажмите «Конвертировать».

EXE собран меньше 25 МБ. Для запуска нужен **.NET 8 Desktop Runtime**. Если FFmpeg уже доступен в PATH, приложение использует его. Иначе при первой конвертации скачает FFmpeg Essentials с сайта Windows-сборок, на который ссылается FFmpeg.org (около 110 МБ), проверит SHA-256 и сохранит в `%LOCALAPPDATA%\C0_0nverter` для следующих запусков. Для первой загрузки нужен интернет.

Для видео доступны H.264, H.265/HEVC, AV1 и VP9. В «Настройках кодирования…» можно переключать CRF/CQ и целевой битрейт, задавать качество, выбирать пресет скорости, высоту кадра, частоту кадров и pixel format, а также выбирать аудиокодек, копирование/отключение аудио и его битрейт. Для AV1/VP9 скорость регулируется параметром CPU-used; для WebM автоматически предлагаются совместимые кодеки.

Контейнеры видео: MP4, MKV, MOV, WebM. Форматы аудио: MP3, WAV, FLAC, OGG и AAC. Выберите аудиоформат, чтобы извлечь и перекодировать звук из видео. Максимальный размер исходного файла — 8 ГБ.

## Сборка

Нужен .NET 8 SDK. Команда:

```powershell
dotnet publish C0_0nverter.csproj -c Release -r win-x64 --self-contained false -p:UseAppHost=true -p:PublishSingleFile=true -p:DebugType=None -p:DebugSymbols=false -o dist
```
